Simple Calculator Using Java

About the Project

This is a console-based calculator developed using Java as part of my CodeOrbit Tech Java Programming Internship.

Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Handles division by zero using exception handling
- Accepts user input using the Scanner class
- Uses a switch statement for arithmetic operations
- Displays results and error messages clearly

Technologies Used

- Java
- Scanner Class
- Switch Statement
- Exception Handling
- Eclipse IDE

How to Run

1. Install Java JDK.
2. Open Eclipse IDE.
3. Open "SimpleCalculator.java".
4. Run the program.
5. Enter two numbers and an operator.

Supported Operators

Operator| Operation
+| Addition
-| Subtraction
*| Multiplication
/| Division
